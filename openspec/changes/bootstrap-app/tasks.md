# Tasks

## 1. Основа проекта и инструменты качества

- [ ] 1.1 Создать npm-проект с Nuxt 4, TypeScript и стандартными командами разработки, сборки и проверки типов; добавить `.gitignore` для зависимостей, артефактов сборки и локальных файлов ОС. Проверка: `npm install` завершается успешно, появляется `package-lock.json`, а `.kimi-code/` не исключена из Git.
- [ ] 1.2 Настроить `ssr: false`, подключить Vuetify 3 через `vuetify-nuxt-module` и Pinia через `@pinia/nuxt`, задать русский язык HTML-документа. Проверка: `npm run typecheck` проходит, а конфигурация содержит только необходимые для каркаса модули без предметных stores.
- [ ] 1.3 Настроить ESLint с Nuxt-интеграцией и строгими Vue-, TypeScript- и stylistic-правилами; добавить `npm run lint` с отказом при любом warning и отдельную команду локального автоисправления. Проверка: `npm run lint` успешно проверяет все исходники и конфигурацию, а намеренно добавленный warning приводит к ненулевому коду выхода.

## 2. Feature-first layout, страницы и навигация

- [ ] 2.1 Создать корневой компонент, `app/layouts/default.vue` и страницы `/`, `/garden`, `/settings` с заголовками «Сегодня», «Мой сад» и «Настройки»; не создавать пустые каталоги `modules`, `domain` и `data` до появления соответствующего кода. Проверка: прямое открытие каждого URL отображает нужный заголовок в общем layout без горизонтальной прокрутки на ширине 390 px, а страницы не содержат бизнес-логики.
- [ ] 2.2 Создать `app/shared/components/AppBottomNavigation.vue` с пунктами «Сегодня», «Сад» и «Настройки», подключить его к default layout и синхронизировать активное состояние с текущим маршрутом. Проверка: каждый пункт доступен касанием, имеет touch-область не менее 44 px, ведёт на правильный URL без полной перезагрузки и визуально выделяется только на соответствующем маршруте.
- [ ] 2.3 Настроить Vitest с Nuxt-совместимым окружением и Vue Test Utils; добавить unit-тест `AppBottomNavigation`, проверяющий пункты, целевые маршруты и активное состояние. Проверка: `npm run test` обнаруживает тест и завершается успешно, а изменение целевого маршрута или правила активного состояния приводит к его падению.
