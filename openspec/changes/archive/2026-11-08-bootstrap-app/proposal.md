# Proposal

## Why

Проект начинается с пустого репозитория, поэтому перед реализацией экранов MVP нужен единый мобильный каркас приложения и понятная навигация между основными разделами. Каркас должен следовать [ТЗ «Персональный агроном»](../../../docs/personal-agronom-mvp.md), не втягивая в первое изменение реализацию продуктовых сценариев.

## What Changes

- Создать основу приложения на Nuxt 4 с TypeScript и SPA-режимом рендеринга.
- Подключить Vuetify 3 для интерфейса и Pinia для будущего управления состоянием.
- Задать базовую цветовую тему на палитрах teal и blue-grey с преимущественно пастельным оформлением и основным текстом `#263238`.
- Задать pragmatic feature-first организацию исходного кода с явными границами между UI, предметной областью и реализациями доступа к данным.
- Настроить официальный `@nuxt/eslint` как базовый набор правил со строгими TypeScript-дополнениями и без допуска warnings, Prettier для форматирования и Vitest для unit-тестов.
- Добавить обязательные проверки качества: линтинг, проверку типов, unit-тесты и production-сборку.
- Добавить скрипт и pre-commit hook для ограничения обычного коммита 40 файлами, предусмотрев повторное использование проверки в будущем CI.
- Задокументировать проверку mobile-интерфейса в Chrome, на реальном телефоне и в Android-эмуляторе.
- Добавить базовый mobile-first layout на русском языке, вынося все пользовательские строки в i18n-словарь и учитывая будущее добавление английского языка.
- Добавить нижнюю навигацию между разделами «Сегодня» (`/`), «Сад» (`/garden`) и «Настройки» (`/settings`) с отображением активного раздела.
- Создать три страницы-заглушки, достаточные для проверки маршрутизации и навигации.
- Не реализовывать данные сада, задачи, репозитории, формы, Capacitor, CI-пайплайн и прочие функции MVP в рамках этого изменения.
- Не добавлять английский словарь, переключатель языка и локализованные маршруты в этом изменении.

## Capabilities

### New Capabilities

- `application-shell`: мобильный каркас приложения, маршрутизация между основными разделами и нижняя навигация с отображением текущего раздела.

### Modified Capabilities

Нет.

## Impact

- Появятся исходные файлы Nuxt-приложения, конфигурация TypeScript, манифест и lockfile выбранного пакетного менеджера.
- В проект будут добавлены зависимости Nuxt 4, Vue 3, Vuetify 3, Pinia, `@nuxtjs/i18n`, ESLint, Prettier и Vitest.
- Будут созданы корневой layout, три основные страницы, компонент нижней навигации и unit-тест его поведения.
- Появятся npm-скрипты для единого локального и будущего CI quality gate.
- Серверная часть, внешние API и модели предметной области не затрагиваются.
