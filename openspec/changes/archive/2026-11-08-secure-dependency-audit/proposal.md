# Proposal

## Why

Свежая установка зависимостей сообщает о 32 известных low/moderate замечаниях npm audit, включая 17 в production-дереве. Предлагаемый npm откат Nuxt, ESLint и других пакетов через `--force` несовместим с принятым стеком, поэтому нужен проверенный способ устранения замечаний и постоянная проверка, предотвращающая их незаметное возвращение.

## What Changes

- Устранить текущие замечания npm audit через совместимые обновления и, при необходимости, точечные overrides без мажорных откатов Nuxt, ESLint, TypeScript ESLint и Vue Test Utils.
- Добавить команды полного и production audit с ненулевым кодом выхода при любом известном замечании.
- Явно включить обе проверки в обязательные quality gates в `openspec/constitution.md` и задокументировать безопасный порядок исправления зависимостей.
- Проверить, что изменения дерева зависимостей не нарушают линтинг, форматирование, типы, unit-тесты и production-сборку.
- Не применять `npm audit fix --force` и не менять продуктовое поведение приложения.

## Capabilities

### New Capabilities

- `dependency-security`: обнаружение известных уязвимостей зависимостей и блокирование изменений при неудовлетворительном результате audit.

### Modified Capabilities

Нет.

## Impact

- Изменятся `package.json` и `package-lock.json`, включая версии transitivных зависимостей и возможные overrides.
- Будут обновлены `openspec/constitution.md` и инструкции по проверкам в `README.md`.
- Исходный код и пользовательское поведение Nuxt-приложения не должны измениться.
