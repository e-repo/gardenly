# Spec Delta

## Purpose

Обеспечивает регулярное обнаружение известных уязвимостей npm-зависимостей и блокирует завершение изменений, пока полное и production-дерево содержат такие замечания.

## ADDED Requirements

### Requirement: Полный audit зависимостей

Проект SHALL предоставлять команду `npm run audit`, которая проверяет production- и development-зависимости и завершается ошибкой при любом известном замечании npm audit.

#### Scenario: Чистое дерево зависимостей

- **WHEN** разработчик запускает `npm run audit` и npm audit не находит известных замечаний
- **THEN** команда завершается успешно

#### Scenario: Обнаружено замечание в любой зависимости

- **WHEN** npm audit находит low, moderate, high или critical замечание в полном дереве зависимостей
- **THEN** `npm run audit` завершается с ненулевым кодом выхода

### Requirement: Production audit зависимостей

Проект SHALL предоставлять команду `npm run audit:production`, которая проверяет только production-зависимости и завершается ошибкой при любом известном замечании в этом дереве.

#### Scenario: Чистое production-дерево

- **WHEN** разработчик запускает `npm run audit:production` и production-зависимости не содержат известных замечаний
- **THEN** команда завершается успешно

#### Scenario: Обнаружено production-замечание

- **WHEN** npm audit находит замечание любой severity в production-дереве
- **THEN** `npm run audit:production` завершается с ненулевым кодом выхода

### Requirement: Обязательная проверка перед завершением изменения

Обе команды audit SHALL входить в обязательные quality gates проекта и MUST успешно выполняться перед завершением и архивированием change.

#### Scenario: Завершение изменения с чистым audit

- **WHEN** полный и production audit завершаются успешно вместе с остальными quality gates
- **THEN** требование безопасности зависимостей для change считается выполненным

#### Scenario: Завершение изменения с замечаниями audit

- **WHEN** хотя бы одна команда audit находит известное замечание
- **THEN** change нельзя считать завершённым или архивировать до устранения замечания

### Requirement: Совместимость исправлений зависимостей

Исправления npm audit MUST сохранять принятые технологические ограничения и работоспособность приложения; автоматические мажорные откаты через `npm audit fix --force` SHALL NOT применяться.

#### Scenario: Применено исправление дерева зависимостей

- **WHEN** обновления или overrides установлены и зафиксированы в lockfile
- **THEN** линтинг, форматирование, typecheck, unit-тесты и production-сборка завершаются успешно без изменения продуктовых сценариев
