# Spec Delta

## MODIFIED Requirements

### Requirement: Отмена и ошибка создания

Пользователь SHALL иметь возможность отменить создание и вернуться к списку без нового участка. При ошибке сохранения приложение SHALL показывать общее уведомление и сохранять введённые значения формы без отдельного alert ошибки создания.

#### Scenario: Отмена создания

- **WHEN** пользователь отменяет создание
- **THEN** он возвращается на `/garden`, а новый участок не добавляется

#### Scenario: Репозиторий отклонил создание

- **WHEN** сохранение завершилось ошибкой
- **THEN** форма остаётся заполненной, появляется общее уведомление с понятным сообщением, а список участков и введённые значения не изменяются
