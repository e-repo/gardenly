# application-shell Specification

## Purpose

Определяет единый мобильный каркас приложения и понятный переход пользователя между его тремя основными разделами.

## Requirements

### Requirement: Доступность основных разделов

Приложение SHALL предоставлять разделы «Сегодня», «Сад» и «Настройки» по маршрутам `/`, `/garden` и `/settings` соответственно.

#### Scenario: Открытие раздела «Сегодня»

- **WHEN** пользователь открывает маршрут `/`
- **THEN** приложение отображает страницу с заголовком «Сегодня»

#### Scenario: Открытие раздела «Сад»

- **WHEN** пользователь открывает маршрут `/garden`
- **THEN** приложение отображает страницу с заголовком «Мой сад»

#### Scenario: Открытие раздела «Настройки»

- **WHEN** пользователь открывает маршрут `/settings`
- **THEN** приложение отображает страницу с заголовком «Настройки»

### Requirement: Нижняя навигация

Приложение SHALL отображать в основных разделах нижнюю навигацию с пунктами «Сегодня», «Сад» и «Настройки» и позволять перейти к каждому разделу одним действием пользователя.

#### Scenario: Переход через нижнюю навигацию

- **WHEN** пользователь находится в основном разделе и выбирает пункт нижней навигации «Сад»
- **THEN** приложение открывает маршрут `/garden` и отображает соответствующую страницу

#### Scenario: Доступность навигации во всех основных разделах

- **WHEN** пользователь открывает `/`, `/garden` или `/settings`
- **THEN** приложение отображает все три пункта нижней навигации

### Requirement: Индикация текущего раздела

Приложение SHALL визуально выделять в нижней навигации пункт, соответствующий открытому основному разделу.

#### Scenario: Активный пункт навигации

- **WHEN** пользователь открывает маршрут `/garden`
- **THEN** пункт «Сад» визуально выделен, а остальные пункты не выделены как активные

### Requirement: Клиентские переходы между разделами

Переходы между основными разделами SHALL выполняться на стороне клиента без полной перезагрузки страницы.

#### Scenario: Переход без перезагрузки

- **WHEN** пользователь переходит из раздела «Сегодня» в раздел «Сад» через нижнюю навигацию
- **THEN** содержимое приложения меняется на раздел «Сад» без полной перезагрузки страницы

### Requirement: Мобильное взаимодействие

Основной layout SHALL быть пригоден для использования на экране шириной около 390 px, а интерактивные элементы навигации SHALL иметь touch-область не менее 44 px и не зависеть от hover.

#### Scenario: Использование на мобильном экране

- **WHEN** пользователь открывает основной раздел на экране шириной 390 px
- **THEN** содержимое и навигация помещаются без горизонтальной прокрутки, а все пункты навигации доступны для нажатия

#### Scenario: Взаимодействие без мыши

- **WHEN** пользователь взаимодействует с нижней навигацией касанием
- **THEN** переходы и индикация активного раздела работают без событий hover
